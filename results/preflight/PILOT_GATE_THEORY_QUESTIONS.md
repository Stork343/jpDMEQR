## 背景事实（已确认，无争议）
- P01-P04 全部行的 PROFILE-DQR 覆盖 0.005-0.37（活跃坐标）与 0.37-0.86（空坐标），
  SE/SD 比值 0.50-0.87。
- oracle 对照 PROFILE-DQR-TRUE-SUPPORT（p=5、无筛选、bias≈0.004）：
  SE/SD 比值仍只有 0.53-0.59，覆盖 0.69-0.75（n=80，P01）。
- 拟合设置：h = n^{-1/3}（n=80 → h=0.232），λ_beta = √(log p/n)（P01: 0.257，
  数据驱动，非 dev 简化），λ_gamma=1。
- sandwich 实现与 METHOD_SPEC §5.5 逐行一致：
  se² = n^{-1} · mean_i{(g_i'ω - mean(g_i'ω))²}，g_i = -m_i^{-1} X_i' ψ_h(r_i)，
  无 df 修正（df_correction=FALSE，n/(n-1) 只影响 1%）。
- Dantzig μ 网格（冻结）：dantzig_multipliers = {0.5,1,2,4} ×
  [(log p/(nh))^{1/2} + h²]；P01 最小 μ = 0.5×0.588 = 0.294（选中），
  P02-P04 最小 μ ≈ 0.263。mean_precision_row_error ≈ 3.9。
- 几何门、identity（~1e-16）、KKT（~1e-7）、Dantzig 可行性（≥0.95）全部通过——
  组件的"正确性"无虞；问题在有限样本的推断性质。

## 问题 1（主）：sandwich 方差在 n=80-120 低估 ~45%，连 oracle 都失败
### 现象
TRUE-SUPPORT（精确逆行、无去偏误差）SE/SD ≈ 0.53-0.59，覆盖 0.69-0.75。
按 n/(n-1) 修正仅得 1.006×，无法解释 1.8× 缺口。n 从 80→120 无明显改善。
### 请理论方裁定
1. 平滑得分的方差亏损：Var(ψ_h(ε)) < τ(1-τ)。估计量的真实抽样方差由
   未平滑残差质量主导；h=n^{-1/3} 时有限 h 方差公式是否应为
   n^{-1}ω'Σ_h ω 加上一个 ~h·f(0)·常数 的项？请给出有限 h 的精确方差公式
   或一个先验的（非调参的）修正。
2. 二阶项：β̃_k = β̂_k - ω'g(β̂) 展开中，精确 ω 下一阶项消失，但
   (1/2)ω'∇²g(β̂)(β̂-β*)² 项为 O(1/(nh))（n=80,h=0.232 → 0.054，量级可观）。
   请量化该二阶项对 Var(β̃_k) 的贡献，并裁定现行 §5.5 公式在 n=80-120
   是否应保留（若保留，[0.80,1.20] 阈值在此 n 是否可达；若不可达，
   是需要方差修正还是调整 pilot 基线 n）。
3. 簇规模不平衡（m_i∈2:8）与 m_i^{-1} 加权的有限样本效应是否需要修正项。

## 问题 2（次）：Dantzig μ 网格在 n=80-120 过粗，去偏失效
### 现象
P01：选中 μ=0.294，精度行误差 3.9；去偏修正（均值 ~0.49）被应用但方向/量级
不准 → 活跃坐标 bias -0.26/+0.63，覆盖 0.005-0.37。TRUE-SUPPORT（精确逆行）
bias≈0.004 → 确认 bias 机制在 ω 的精度，不在目标/数据生成/得分定义。
μ 的速率 (log p/(nh))^{1/2} 在 n=80 比 1/√n 大约 n^{1/6}=2.1 倍；
去偏误差 O(μ·‖ω‖₁·‖g‖∞) 在 λ=0.257、‖ω‖₁~10-50 下量级为 0.3-0.6。
### 请理论方裁定
1. 冻结网格 {0.5,1,2,4} 的最小乘子 0.5 是否即设计意图？是否需要更小乘子
   （0.1/0.25）或自适应 μ（如按 ‖H^{-1}e_k‖₁ 校准）？
2. 冻结接受标准"残差 ≤ μ+1e-6"只验可行性、不验行精度；是否应增加
   行精度诊断（如 precision_row_error 上界）作为 gate 项？
3. 若 μ 缩小到 0.05-0.1，CLARABEL 在 p=200-300 可解（几何门已用
   μ={0.05,...,0.8} 验证过小尺度），行精度是否会达到可接受水平——
   请给出去偏误差关于 μ 的精确界，供选择网格。

## 问题 3：交互与后续影响
1. 若方差公式修正：修正是否影响"最终注册表"的方法设置（λ、μ、h 不动，

2. 若 μ 网格变化：仅影响分析层（目标资产、方向资产、几何门均不依赖分析 μ），
