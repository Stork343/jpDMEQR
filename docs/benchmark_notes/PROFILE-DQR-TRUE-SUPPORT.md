# PROFILE-DQR-TRUE-SUPPORT

This oracle selection diagnostic uses the profile parameter and equations
in `docs/METHOD_SPECIFICATION.md`. The fitted design contains the generated
active coordinates and prespecified inference coordinates. All retained
coefficients have zero L1 penalty. The complete convex profile is refitted
at the inference bandwidth, followed by the paired score, paired Dantzig
direction and paired-score cluster sandwich.

The adapter maps coefficients and predictions to the original named design.
The returned selection identifies the oracle design. Its use of the active
set is restricted to this explicitly labelled diagnostic. Allowed metrics
are estimation, prediction, coordinate coverage and the oracle selection gap.

The paired benchmark test compares this adapter with a direct zero-penalty
fit on exactly the same reduced observations and columns. It checks
deterministic estimates and numerical score identities, and tests predictions
on the original design. The implementation and dependencies follow the
PROFILE-DQR source note. Acceptance records are generated by
`scripts/benchmarks/accept_profile_pair_20261022.R`.
