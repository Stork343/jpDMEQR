# 粪便代谢物与炎症分布

本研究以同一次粪便采样的代谢物测量和 calprotectin 为对象，考察上分位数炎症水平的预测及代谢物关联。结局为公开 calprotectin 读数的自然对数，预定评价分位数为 0.75，同时报告 0.25 与 0.5 的结果。

记录按 site_sub_coll 匹配同次采样。fecalcal 与 fecalcal_ng_ml 的重叠记录须在 0.001 以内一致；存在 fecalcal_ng_ml 时保留其较完整的小数精度。该字段标记的单位为 ng/ml。全部匹配均要求患者编号一致。

具有名称的代谢物按原研究的 pooled QC 规则选取变异系数最低的测量，并保留 QC 变异系数不超过 0.3 的项目。模型训练时要求正值比例至少为 20%。零值使用对应训练部分最小正值的一半进行 log2 变换；随后减去同次采样在对应测量方法下的正值信号 log2 中位数。训练部分决定变量保留和标准化。年龄、诊断、性别与采样时间作为候选变量，同时包含采集地点、用药及各测量方法的样本信号水平。预测模型始终包含截距，其他候选变量按相同规则正则化。

患者分组在结局关联分析之前生成。每个采集地点预留约 20% 的完整患者用于正式验证；其余患者分成五个评价折。每个评价折的训练部分进行三个患者交叉验证折，所有变量变换和均值背景学习都在相应训练部分进行。每个患者获得相同权重，其采样记录共同分配该权重。

比较包括均值背景加 JOINT 稀疏修正、相同背景和输入下的 exact quantile Lasso、校准后的 ridge 与 elastic net，以及直接 JOINT 模型。临床候选变量在全部方法中相同。第 75 分位数的五个患者评价折全部完成后计算配对损失差异。获得可继续研究的线性比较结果后，开展原始响应与残差响应的 quantile forest 比较。

数据来源为 Lloyd-Price 等人的 IBDMDB 研究。原研究已报告代谢物与疾病活动的混合模型关联。本次分析检验同次采样的炎症分布，并要求新发现具有可重复的分位数差异。所有探索结果保留，正式验证使用确定后的研究问题、比较方法及错误概率分配。
