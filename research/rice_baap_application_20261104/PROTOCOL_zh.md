# 灌溉方式与水稻镉积累的分位数研究

研究使用 Norton 等人在 2021 年报告的 BAAP 镉浓度数据，以及作者保存于 Harvard Dataverse 的基因型文件。原研究发现了基因型与灌溉方式之间的交互作用，但未识别出明确的灌溉条件专属位点。这里检验遗传关联是否随镉浓度分布的位置改变，以及联合 profile 方法能否改善新水稻品种的分位数预测。

公开表格中的每个浓度是一个品种在指定年份及灌溉条件下至少三次田间重复的平均值，单位为微克每千克。分析将这个已报告的平均值作为观测响应，使用其自然对数。同一品种最多有四项响应，分别来自 2013 年和 2014 年的 AWD 与 CF 条件。缺失响应保持缺失。基因型使用作者发布的 Beagle 处理结果，记录其来源及 A1 等位基因计数规则。

品种通过作者的 BAAP 编号连接。全部记录随品种共同分配探索和正式验证角色，探索数据进一步分为训练和评价部分。评价分位数固定为 0.75，其余两个分位数为 0.25 和 0.50。读取正式验证结果之前，需要确定具体遗传关系、比较方法及检验范围。

每个训练分组单独执行标记频率筛选和 LD 筛选。保留训练频率至少 0.05、缺失比例至多 0.10 的标记，并在 250 kb 窗口内使用 0.8 的平方相关阈值。筛选过程仅使用基因型。群体结构的前三个分量同样在训练品种中估计，评价品种使用对应投影。所有比较方法使用同一训练分组生成的标记集合。

设计矩阵包含标记效应及标记与灌溉方式的交互项。年份和灌溉条件进入共同调整集合，群体结构分量及其与灌溉方式的交互也包含在内。品种 nuisance 使用截距和中心化年份两个方向，工作惩罚为固定正定矩阵。预测调参使用 0.5、1 和 2 乘以单位矩阵的候选，最终坐标推断遵循手稿中固定工作惩罚的 profile 参数定义。

预测比较包含 Elastic net 与精确分位数 Lasso。Ridge 使用从 1000 至 0.00001 的误差与遗传方差比网格，其余 Elastic net 路径采用训练最大惩罚的几何比例。训练分组的预测残差按田间环境进行分位数校准。每个品种在损失函数中获得相同权重，较多观测的品种不会因记录数量得到较大权重。出现预测改善的候选继续与分位数森林比较，并检查已有遗传研究及独立验证结果。

基因型由 PLINK 2.0.0 b.1.3 转换及筛选，R 使用 BEDMatrix 2.0.4 读取。Python 的 bed_reader 与 R 的 BEDMatrix 对真实基因型进行独立读取核查。矩阵按变量组构造，以控制内存使用。源文件、配置与检查结果保存于 GitHub，原始数据和拟合对象保存至项目备份目录。

数据论文 DOI 为 `10.1007/s10681-020-02752-1`，基因型数据 DOI 为 `10.7910/DVN/AUMTIH/VVSRBW`。原研究已确认的 OsHMA3 和 OsNRAMP1 关联属于已有知识；新的遗传解释需要通过本研究的比较及验证程序。
