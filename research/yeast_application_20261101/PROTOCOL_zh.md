# 应激生长的分位数研究

研究使用 Bloom 等人在 2013 年发表的独立菌株及重复生长测量。每个四分体仅选取一个后代，原始数据包含 1008 个菌株。表达数据来自 Albert 等人在 2018 年对同一菌株集合进行的 RNA-seq 测量。表达记录和原始菌株标识逐一对应，遗传标记与表达变量同时进入调整集合。

研究问题是转录状态与应激条件下较低生长表现的关系，以及联合 profile 方法能否改善相同输入信息下的分位数预测。采纳的预测检验针对 0.25 分位数，0.50 和 0.75 分位数完整报告。应激条件在探索阶段使用统一规则比较。RNA-seq 生长分组依据既往 YNB 测量构造，因此正常培养基测量保留为实验背景资料。

原始菌株按固定随机种子分配探索与正式验证角色。探索数据进一步按菌株分成训练和评价部分，三个训练分组选择模型参数。表达批次、RNA 采集时的 OD 和重复测量位置进入调整集合。每个训练分组单独计算变量标准化及响应尺度。缺失的生长测量保留缺失状态，分析使用实际观测。

均值比较采用 elastic net，并通过训练菌株选择 alpha 及惩罚参数。均值方法与联合 profile 方法使用相同的表达和遗传信息。分位数校准使用训练分组的预测残差。发现预测优势的候选继续与直接分位数方法及 QRF 比较，随后确定待验证的生物学问题。

全部候选的正式验证顺序在读取任何验证结果之前确定。验证阶段需要同时确认方法优势和具体的科学增量，之后才能更新手稿。2015 年的再次测量按共享遗传标记核查菌株身份，符合匹配要求的记录保留重复实验角色。

原始数据来源为 `http://genomics-pubs.princeton.edu/YeastCross_BYxRM/data.shtml`，研究 DOI 为 `10.1038/nature11867`。RNA-seq 数据与处理程序来自 `https://github.com/joshsbloom/eQTL_BYxRM`，研究 DOI 为 `10.7554/eLife.35471`。再次测量的来源为 DOI `10.1038/ncomms9712` 的 Supplementary Data 5。
