# 冠层信息与大豆产量分布

SoyNAM田间试验提供了40个家系的5,533个大豆品系。每个品系在2013年和2014年各有一条记录，合计11,066个小区观测。4,235个基因组标记分别与年份交互，连同冠层及其他调整变量，构成8,526列设计矩阵。样本单位是品系，每个品系具有两次测量；这与我们的方法所处理的高维混合效应分位数模型相符。

调整全部记录的基因组标记及其年度交互后，冠层覆盖度仍与产量正相关。模型同时控制家系和田间条件，并调整记录中的成熟期。下表表示冠层覆盖度每增加10个百分点所对应的profile产量关联，单位为bu/ac，即蒲式耳每英亩。区间共同控制六个年度分位数系数和五项预定差异的95%同时置信水平。

| 年份 | 分位数 | 产量关联 | 同时置信区间 |
| --- | --- | --- | --- |
| 2013 | 0.25 | 4.54 | [ 3.31, 5.77 ] |
| 2014 | 0.25 | 4.35 | [ 3.13, 5.57 ] |
| 2013 | 0.50 | 3.96 | [ 3.01, 4.91 ] |
| 2014 | 0.50 | 5.16 | [ 4.19, 6.13 ] |
| 2013 | 0.75 | 3.85 | [ 2.79, 4.90 ] |
| 2014 | 0.75 | 5.45 | [ 4.37, 6.53 ] |

2014年的上四分位数关联比2013年高1.61 bu/ac，同时置信区间为[ 0.14, 3.07 ]。七项设置中的差异估计介于1.50至2.02 bu/ac，所有相应区间均为正。增加田间空间项之后，这项年度差异继续得到支持。

## 留出品系的预测

预测训练使用4,426个品系，另外1,107个品系的两年记录全部留出。每种方法共用田间对照小区提供的校准信息；品系层面的预测变量包括基因型和冠层。截距校准来自训练样本的内部验证残差。下表比较包含冠层的joint profile预测与仅包含基因组和田间信息的同类预测，正值表示加入冠层后的pinball loss降低比例。

| 分位数 | 预测损失降低比例 | 同时置信区间 |
| --- | --- | --- |
| 0.25 | 1.52% | [ -0.41, 3.44 ]% |
| 0.50 | 1.58% | [ -0.24, 3.40 ]% |
| 0.75 | 2.27% | [ 0.64, 3.91 ]% |

在上四分位数，预测损失下降2.27%，同时置信区间为[ 0.64, 3.91 ]%。冠层测量对这批留出品系的产量上四分位数预测提供了额外信息。下四分位数和中位数的区间包含零，其估计增益也已保留在表格中。

## 计算及数据来源

21项预定推断均已完成。六个冠层系数在所有设置下都保持正向，同时置信区间均为正。带宽上下调整25%时，参考系数的最大变化约为0.010 bu/ac。三个参考分位数的完整推断需要约9.5至11.9分钟，包含变量选择和两个带宽的系数估计，计算设备为配备36 GB内存的Apple M3 Max。

数据来自[NAM数据文档](https://search.r-project.org/CRAN/refmans/NAM/html/met.html)所说明的公开面板，测量设计见[Xavier等2017年的研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5499164/)。产量单位和田间小区记录经过SoyNAM数据字典与相同小区的交叉核对。原始数据保留来源中的数值，计算结果按品系保存，并复制至独立备份目录。
