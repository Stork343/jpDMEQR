# 血浆蛋白与血红蛋白分布

研究对象为 Charité 队列的血浆蛋白和临床血红蛋白记录。研究检验蛋白质能否改善新患者血红蛋白第 25 分位数的预测，以及蛋白质与血红蛋白的关联是否随分位数变化。第 50 和第 75 分位数共同报告。结局保留 g/dl 单位，使用全部有效的正值记录。

数据来自 DOI 10.1016/j.cels.2021.05.005 的 Table S8、Table S9 和 Table S10。原研究在采样当日缺少临床记录时使用之前两天以内的最近记录。因此，本研究预测公开资料中与蛋白质采样配对的临床读数。原始记录包含 139 名患者和 687 次采样，血红蛋白分析包含 133 名患者的 667 次有效记录。

蛋白质候选采用作者报告至少三个肽段的蛋白质组。包含血红蛋白基因的蛋白质组从预测变量中移除。蛋白质取 log2 后，按训练患者的权重计算缺失比例与标准化参数；缺失值采用训练患者加权中位数填补，并增加训练部分出现过的缺失指示变量。每个患者获得相同权重，其记录共同分配该权重。年龄、BMI、Charlson index、入院后时间和当前 WHO grade 为临床候选变量。

患者编号在任何模型关联分析之前分组。按第一次有效记录的 WHO grade 是否达到 6 分层，约 70% 的完整患者用于训练，其余用于一次验证。训练部分采用三个完整患者折选择参数。所有模型拟合与蛋白质目标选择完成后，才计算验证患者的预测和关联结果。验证结局不用于选择模型、变量或校准量。

预测比较包括 JOINT_OFFSET、直接 JOINT、原始响应及相同 offset 下的 exact quantile Lasso、经过分位数校准的 elastic net 与 ridge，以及仅使用临床变量的 quantile regression。非线性比较包含原始响应和 offset 响应下的 quantile forest 与 XGBoost quantile regression。原研究使用 XGBoost 分类治疗需求，本研究使用原生 quantile loss 回答血红蛋白预测问题。全部方法使用相同的原始输入信息和患者分组。

各分位数按训练交叉验证损失选择参数。最终预测统一限制在非负范围，并对三个分位数的预测值排序，以得到有序的预测曲线。排序后的预测是预定评价对象，原始预测作为敏感性结果保存。评价损失先在患者内求平均，再在患者之间求平均。计算配对患者 bootstrap 区间，判断 JOINT_OFFSET 是否优于每一项比较方法。

关联分析预先指定 HP、HPX 和 TF，分别代表血红蛋白结合、血红素清除与铁运输。训练数据还选择三个蛋白质，选择依据为第 25 与第 75 分位数的完整预测斜率差异。完整斜率包括 ridge 背景和稀疏修正的共同贡献。只在具有单一基因名称且训练可观测比例至少为 90% 的蛋白质中选择新增目标。

验证样本采用同一套临床变量和选定蛋白质设计，使用 jp_fit_fixed 的两个带宽配对系数和患者级 influence。三个分位数均固定 Lambda 为 1，响应及蛋白质尺度由训练数据确定。推断对象是这一固定设计下的 regularised profile association。估计前仅依据设计矩阵移除无法识别的临床列；目标蛋白质列需要可识别。比较第 25 分位数与第 50、第 75 分位数的关联差异，并用完整协方差计算区间。默认带宽为 n^(-3/10)，另外报告 0.75 和 1.25 倍带宽结果。

本次验证为数据筛选过程的第 1 次正式尝试，总错误概率为 0.025。其中 0.0125 分配给预测比较，要求全部比较方法的单侧区间下界均大于零；另外 0.0125 用于蛋白质差异检验，在全部预定对比中进行 Bonferroni 调整。采纳需要同时通过预测比较和具有明确解释的分位数关联差异检验。其余分位数、原始预测及带宽敏感性结果均保持原有标签。
