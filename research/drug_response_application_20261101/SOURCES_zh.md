# 数据与相关研究

GDSC 原始实验记录来自 Cell Model Passports 的下载目录。GDSC1 文件为 `GDSC1_public_raw_data_27Oct23.zip`，基因表达文件为 `rnaseq_20191101.zip`。每个实验保留实验板、孔位和药物浓度。表达数据提供 Sanger 与 Broad 来源标识，数据转换与缺失值填补使用对应训练样本。

`gdscIC50` 0.99.4 采用作者仓库版本 `34d842254a33bd04f318449969ff9976237c9295`。处理过程读取质量标识，并通过同一实验板的 `NC-0` 与 `B` 对照计算标准化读数。

Koukouli 等人的 2021 年研究已经分析基因与剂量的变化关系，并识别 BRAF 药物相关通路。其 DOI 为 `10.1371/journal.pcbi.1008066`。2018 年的 QRF 研究讨论药物反应预测区间，DOI 为 `10.1371/journal.pone.0205155`。Wang 等人的研究通过 Gaussian process 传播剂量反应测量的不确定性，DOI 为 `10.7554/eLife.60352`。Iversen 等人的 2026 年研究进一步分析与预测不确定性有关的表达特征，DOI 为 `10.1093/bioadv/vbag246`。

本项目需要检验的是，经其他表达变量调整之后，具体基因的剂量关联如何随分位数改变，以及这些差异能否在保留患者与另一轮测量中重复。预测改进需要同时面对 functional regression 和直接分位数预测方法。现有数据核查与程序检查尚未完成这些科学检验。
