# 温度与开花时间分布

研究 10°C 和 16°C 培养条件下开花时间分布的遗传关联，重点考察较早开花部分的温度差异。表型来自 AraPheno 的 FT10 和 FT16，基因型采用 1001 Genomes 发布的 imputed SNP matrix。原实验在随机区组中设置四个重复，开花时间记录至第一朵花开放；公开表型为重复测量的均值，以天为单位。原文补充方法没有规定将未开花植株赋予固定上限，公开表型文件也没有删失状态字段。本分析使用已发表的开花时间均值。

纳入具有两种温度表型和基因型的品系。来源中的 obs_unit_id 原样保留，accession_id 为聚类单位。Kas-2 的两个来源 observation units 在两种温度下均有记录，统一归入同一品系，最多产生四条记录。统计样本量按品系计数，损失按品系平均。各品系在关联分析前分配角色，预留验证结果在问题和比较方法固定后使用。

基因型频率与 LD 筛选只使用相应训练角色。采用 250 kb 窗口和 r²=0.2 保留基因型信息较少重复的标记，减少训练矩阵的存储和计算；筛选过程不读取响应。SNP 输入保存为作者二元编码的两倍，PLINK 的 ONE 和 ZERO 仅表示原矩阵的两个状态。按照训练品系标准化后，这一线性编码保留原变量。基因组 PC、响应尺度与后续调参均由训练部分决定。固定设计包括温度、五个 PC、这些 PC 与温度的交互项，以及 SNP 和 SNP 与温度的交互项。JOINT 的 nuisance 为品系截距。

预定筛选分位数为 0.25。首先比较 JOINT、经过训练残差校准的 ridge 和 elastic net，以及 exact quantile Lasso。具有探索改善的候选继续完成非线性分位数和相关公开预测方法比较。原研究已经报告 FT、SVP、FLC、VIN3 等开花调控区域，后续研究也分析了温度响应。新的结论需要具体的分位数关联差异及预留品系中的方法优势。

数据来源为 DOI 10.1016/j.cell.2016.05.063、10.21958/phenotype:261 和 10.21958/phenotype:262。分析使用作者公开的 Beagle 填补后基因型，响应保持原始公开数值。当前处于数据筛选阶段，manuscript_adoption 为 false。
